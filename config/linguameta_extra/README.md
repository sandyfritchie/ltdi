# Languages added to LinguaMeta's records

LinguaMeta covers living, spoken languages, so it leaves out historical and classical ones. These
records, in LinguaMeta's own format, add the few the Index includes anyway because technology supports
them and people look for them. `ltdi.backbone.records()` reads them after LinguaMeta's, and a LinguaMeta
record with the same code takes precedence, so they drop out if LinguaMeta adds the language.

| Code | Language | Speakers | Source |
|---|---|---|---|
| sa | Sanskrit | 24,821 | Census of India 2011: people who returned Sanskrit as their mother tongue, from the Ministry of Home Affairs' answer to Lok Sabha starred question 292, 16 March 2021 (https://www.mha.gov.in/MHA1/Par2017/pdfs/par2021-pdfs/LS-16032021/292.pdf) |
| la | Latin | none | No first-language speakers; a working language of the Holy See (Glottolog: second language only). Scored, with a page, but not ranked, like the other languages no longer spoken |

Coordinates are Glottolog's (sans1269, lati1261).
